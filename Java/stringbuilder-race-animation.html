What went wrong? (the 3-step append)

  1. READ count — both threads see count = 0 at the same time.
  2. WRITE chars — T1 writes "A","B" at index 0,1. T2 also writes "A","B" starting at index 0 (because it still thinks count is 0!) → overwrite.
  3. UPDATE count — both set count to 2. Final count is 2, not 4. Two characters lost.
  4. StringBuffer fix — synchronized append() means T2 waits until T1 finishes all 3 steps. Result: "ABAB", count = 4.
